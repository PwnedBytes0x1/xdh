# Security Policy

The `xdh` maintainers and community take security vulnerabilities seriously. We appreciate responsible disclosure to help protect users across all operating platforms.

---

## Supported Versions

Security updates are actively provided for the following releases:

| Version | Supported |
| :--- | :--- |
| **1.0.x** | ✅ Full security and patch support |
| **< 1.0** | ❌ Unsupported |

---

## 🔒 Reporting a Vulnerability

If you discover a security vulnerability within `xdh`, please **do NOT report it via public GitHub issues**.

Instead, please report responsibly through one of the following methods:

1. **GitHub Private Advisory**: Open a confidential advisory report via [GitHub Security Advisories](https://github.com/PwnedBytes0x1/xdh/security/advisories/new).
2. **Direct Email**: Send full details directly to **pwnedbytes@gmail.com** with the subject line `[SECURITY] xdh Vulnerability Report`.

### Please Include:
- A description of the vulnerability and its potential security impact.
- Clear, reproducible step-by-step instructions or Proof of Concept (PoC).
- Affected version(s) and operating system environment.
- Any suggested mitigations or patches if available.

---

## ⏱️ Response Timeline

- **Acknowledgment**: Within 48 hours of initial receipt.
- **Triage & Assessment**: Usually within 3 business days.
- **Fix & Disclosure**: Coordinated release and CVE assignment (if applicable) prior to public announcement.

We kindly request that you allow reasonable time for a fix to be published before any public disclosure.
